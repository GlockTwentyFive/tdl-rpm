# tdl RPM

RPM packaging for **tdl**, a Telegram toolkit written in Go.

This repository contains the RPM spec file used to build a binary package from the official upstream release archives. The package is intended for use with Fedora and COPR.

## Supported Architectures

* x86_64
* i686
* aarch64

## COPR

The package can be built directly in a COPR project using the included `tdl.spec` file.

## Upstream

* Repository: https://github.com/iyear/tdl
* Documentation: https://docs.iyear.me/tdl/
